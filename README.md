# Sistema de Gestión de Solicitudes Académicas

Versión inicial del Trabajo Práctico Integrador de Metodología de Sistemas II.

## Funcionalidades

- Registrar estudiantes.
- Registrar responsables académicos.
- Registrar solicitudes.
- Asignar responsables.
- Cambiar estados.
- Buscar solicitudes.
- Generar un reporte por estado.
- Persistir información en JSON.

## Tecnología

- Python 3.11 o superior.
- Biblioteca estándar.
- unittest.
- Persistencia mediante archivos JSON.

## Ejecución

```bash
python app.py
